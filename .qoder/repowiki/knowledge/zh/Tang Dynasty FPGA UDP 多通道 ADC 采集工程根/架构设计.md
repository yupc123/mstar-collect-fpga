根目录仅保留构建元数据（`.gitignore`、`LICENSE`、`README.md`、`tand_udp_devicesetting.cfg`），实际源码由两个子模块按职责分层：
- `hdl_source/` 提供可综合的 Verilog/SystemVerilog 顶层 `mstar_udp_top.v`，串联 ad_driver、collect、axi_dma、udpip、sync 等采集与协议栈子模块。
- `ip_cores/` 提供 Anlogic P1 平台的预验证 IP（MIS_DDR、AXI Matrix、sysPLL、AXIS FIFO 等）。
两者通过 `tand_udp.al` 中的 `<IP_FILE>` 节点与 CompileOrder 字段耦合：IP 核注册到 `design_1` FileSet，RTL 源与约束（ADC 引脚 `.adc`、SDC 时序 `.sdc`）归入 `constraint_1` FileSet，由 syn_1 → phy_1 两条 Run 顺序执行综合与布局布线；物理设计策略启用 bin 输出与时序优化。子模块之间无共享代码，仅依赖顶层实例化契约与 IP 接口契约。
